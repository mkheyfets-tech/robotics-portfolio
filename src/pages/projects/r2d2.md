## Helping a robot understand where it is

R2-D2 is a differential-drive robot developed in WPI's Unified Robotics II course. It uses several types of sensor feedback to follow lines, navigate a maze, align with markers, and approach objects.

The C++ control system connects low-level wheel control with higher-level navigation. Wheel encoders and gyroscope readings support pose estimation, while camera and range data provide information about the surroundings.

## Navigation and control

**PI speed controllers** regulate the drivetrain. Forward and inverse kinematics relate wheel motion to the robot's position and orientation, allowing the software to command target poses and in-place turns.

An **OpenMV camera** detects AprilTags. Tag IDs and estimated distances guide routing decisions through the maze, including when to stop at an exit marker. Reflectance sensors support line following and intersection detection.

## Making sensor readings useful

Ultrasonic and infrared sensors measure distance during object approach. Software hysteresis and a hardware Schmitt trigger help prevent noisy readings from causing repeated switching near a threshold.

The project also includes a payload-weighing setup using a strain gauge load cell, a Wheatstone bridge, amplification, and an HX711 converter. Calibration through linear regression and averaging turns the readings into a mass estimate.

## What the project brings together

The main engineering task was coordinating sensing and action: estimating motion, deciding what a marker means, and responding without letting noisy measurements dominate the behavior. The result is a platform for exploring those interactions in a physical environment.
